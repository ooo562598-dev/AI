01 · 报错信息

把它当成导航，不是判决

一条错误信息常包含：错误名字、发生了什么、在哪一行。英文不用全翻译，先抓最稳定的关键词。

🧭
像地图上的定位点

它不一定直接给出答案，但会把范围从整个项目缩小到某个文件、某一行附近。

Console
ReferenceError: userName is not defined
    at app.jsx:4:13
ReferenceError

使用了电脑找不到的名字。

userName

真正出问题的变量名，是最重要的线索。

4:13

第 4 行、第 13 个字符附近。先去那里看。

02 · 三种高频错误

先认识名字，不用背全部

1
SyntaxError：句子没写完整

常见原因是少括号、少引号、多了一个符号。

2
ReferenceError：名字找不到

检查拼写、大小写，以及变量是否在使用前创建。

3
TypeError：这个东西不能这样用

例如元素没找到却继续改它。检查选择器和数据类型。

固定排查顺序

① 先读最后一条红色信息；② 找文件和行号；③ 检查该行上下各 3 行；④ 一次只改一个地方；⑤ 再运行验证。

03 · 调试习惯

不要一慌就重写

使用 console.log() 可以让程序在关键步骤告诉你“现在的数据是什么”。它像沿路放的小路标。

app.jsx
const count = 3;
console.log("当前数量：", count);
const nextCount = count + 1;
console.log("更新后：", nextCount);
