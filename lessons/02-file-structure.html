01 · 项目文件夹

先找到装全部文件的“大盒子”

一个网站项目通常有一个最外层文件夹，叫做项目根目录。这里的“根”就是起点，不是难懂的新功能。

🎒
像整理书包

课本放主体内容，彩笔负责装饰，遥控器负责动作。文件名不同，是为了让人容易找到职责。

my-first-site/
my-first-site/
├── index.html      # 页面内容
├── styles.css      # 页面样式
├── app.jsx         # 页面互动
└── images/
    └── avatar.png  # 图片素材
index.html

通常是浏览器最先打开的首页文件。

styles.css

集中放颜色、大小、间距、布局等视觉规则。

app.jsx

放点击、输入、计算等需要执行的步骤。

images/

文件夹可以继续装文件，避免根目录太乱。

02 · 文件如何连接

HTML 是集合点

浏览器先打开 HTML，再由 HTML 告诉它去哪里找 CSS 和 JavaScript。这个“去哪里找”的文字就是路径。

index.html
<link rel="stylesheet" href="styles.css">
<script src="app.jsx"></script>

同一文件夹里，直接写文件名就够了。进入子文件夹写 images/avatar.png；返回上一层写 ../styles.css。

03 · 常见错误

为什么文件明明在，却找不到？

!
文件名大小写不一致

Styles.css 和 styles.css 在很多服务器上不是同一个文件。

!
少写了一层文件夹

图片放在 images 里，路径就应该包含 images/。

!
扩展名被隐藏

看似 index.html 的文件可能实际叫 index.html.txt。打开系统的“显示文件扩展名”更安全。
