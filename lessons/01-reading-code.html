01 · 先理解

像读菜谱一样读代码

菜谱不会只写“做一道菜”，而会写成准备、加热、装盘几个步骤。代码也是一样：电脑按照我们写下的顺序，一步一步做。

🍳
生活化理解

先拿出鸡蛋，再打开火，最后下锅。如果顺序颠倒，结果就可能不对。代码中的先后顺序也有意义。

先看一个真的 JavaScript 例子

app.jsx
// 先记住今天学了多久
const minutes = 15;

// 再把结果显示出来
const message = `今天学习了 ${minutes} 分钟`;
console.log(message);
第 1 行

// 后面是注释，只是提醒读代码的人，电脑会忽略它。

第 2 行

把数字 15 放进名叫 minutes 的小盒子。

第 5 行

把数字放进一句话，得到完整的学习记录。

第 6 行

让控制台把这句话显示出来。

02 · 读代码的方法

一次只回答 3 个问题

看到陌生代码时，不需要立刻知道每个符号。先问：它拿到了什么？它做了什么？最后得到什么？

缩进像书里的段落。向右缩进的代码，通常属于上面某个结构。先看最左边的“大步骤”，再看里面的小步骤。

缩进示例
if (minutes > 10) {
  console.log("完成今日目标");
}
if

意思是“如果”。先检查括号里的条件。

缩进处

只有条件成立，里面缩进的这行才会运行。

}

右花括号表示这一组小步骤结束了。

03 · 常见误区

新手最容易卡在哪里？

!
试图一次看懂每个词

先找整体动作，再查陌生词。就像第一次看地图，先找方向，不用先记住每条小路。

!
忽略大小写

message 和 Message 对电脑来说是两个名字。

!
删掉一个看不懂的括号

先别删。成对的括号通常表示一段范围，后面会专门练习。
