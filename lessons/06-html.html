01 · 元素与属性

标签说明“它是什么”

HTML 元素由开始标签、内容、结束标签组成。属性是写在开始标签里的补充信息，例如链接要去哪里。

index.html
<h1>我的学习主页</h1>
<p>从今天开始记录进步。</p>
<a href="/courses">查看课程</a>
h1

页面最重要的主标题，一个页面通常只有一个。

p

一段普通正文，适合完整的句子。

a + href

a 创建链接，href 告诉浏览器点击后去哪里。

02 · 页面结构

像整理一篇文章

header 放开头信息，main 放页面主要内容，section 把相关内容分组，footer 放结尾信息。它们的默认样子并不特别，价值在于结构清楚。

语义结构
<header>网站名称</header>
<main>
  <section>
    <h1>今日学习</h1>
    <p>完成 HTML 基础。</p>
  </section>
</main>

表单让用户输入

label 是输入框的说明，input 负责接收内容，button 负责提交或触发操作。给 label 的 for 和 input 的 id 写同一个值，它们就连接起来了。

03 · 常见错误

能显示，不等于结构合适

!
所有东西都用 div

div 可以分组，但标题仍应该用 h1/h2，按钮仍应该用 button。

!
为了变大使用 h1

标签表达含义，大小应该交给 CSS。不要把普通文字当标题。

!
图片没有 alt

alt 用文字说明图片内容，让图片无法显示或使用读屏器时仍能理解。
