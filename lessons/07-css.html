01 · CSS 规则

找到谁，再改变什么

一条 CSS 规则由选择器和花括号里的属性组成。选择器说“改谁”，属性说“改什么”。

🎨
像给房间下装修单

“把客厅的墙刷成绿色”：客厅是选择器，墙面颜色是属性，绿色是属性值。

styles.css
.card {
  background: #eef4ea;
  color: #203025;
  border-radius: 16px;
}
.card

点号表示寻找 class="card" 的元素。

background

改变背景颜色。

color

改变文字颜色。

16px

px 是像素单位，这里让四角变圆。

02 · 盒模型与布局

每个元素都像一个盒子

内容外面依次是 padding 内边距、border 边框、margin 外边距。文字挤在边缘时，通常要加 padding；两个盒子太靠近时，用 margin 或 gap。

Flex 布局
.actions {
  display: flex;
  align-items: center;
  gap: 12px;
}

display: flex 让子元素排成一行；align-items: center 让它们垂直居中；gap 负责它们之间的空隙。

03 · 常见错误

规则写了却没变化？

!
选择器没有选中元素

HTML 是 class="card"，CSS 就要写 .card；少了点号会选中名为 card 的标签。

!
少了单位

padding: 20 通常无效，应写 20px。

!
被后面的规则覆盖

同样重要时，后写的规则会生效。打开浏览器检查工具能看到被划掉的属性。
