01 · 找到元素

先告诉 JavaScript 要操作谁

浏览器把 HTML 整理成一棵可以操作的树，叫 DOM。你不用背这个缩写，只需要知道：JavaScript 能用 CSS 选择器找到页面元素。

🎯
像先拿到遥控器

想换台之前要先找到电视；想改按钮之前，也要先找到那个按钮。

app.jsx
const button = document.querySelector("#checkButton");
const status = document.querySelector("#status");
document

当前网页这份文档。

querySelector

按照选择器寻找第一个符合的元素。

#status

# 表示寻找 id="status" 的元素。

02 · 等待与改变

点击发生时，执行一个函数

app.jsx
button.addEventListener("click", () => {
  status.textContent = "今天已完成";
  button.classList.add("is-done");
});
click

要等待的事件名称：用户点击。

() => {}

事件发生后要执行的函数。

textContent

把元素显示的文字换成新内容。

classList.add

给按钮添加一个 class，让 CSS 改变它的样子。

03 · 常见错误

为什么点击没有反应？

!
选择器和 HTML 对不上

HTML 是 id="checkButton"，JavaScript 就要写 #checkButton。

!
把函数提前调用了

监听器需要函数本身，不要写成 handleClick()，否则加载时就运行。

!
脚本运行得太早

如果 HTML 还没出现就去找元素，会得到 null。把 script 放在 body 最后是简单做法。
