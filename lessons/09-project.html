01 · 先拆需求

不要一上来就写代码

先把想做的东西写成小清单：显示学习主题、显示连续天数、显示一周状态、点击按钮后完成今天。这四条就是开发路线。

先画地图，再开始走

每完成一项就验证一次。HTML 完成时先看内容，CSS 完成时看布局，最后才连接点击。

项目结构
<article class="check-card">
  <header>...主题和天数...</header>
  <div class="week">...一周状态...</div>
  <button id="checkButton">完成今日打卡</button>
</article>
article

把完整、独立的一张学习卡片包起来。

header

放卡片最重要的主题和连续天数。

.week

一组相同的星期状态，CSS 会用 Flex 排列。

#checkButton

唯一 id 方便 JavaScript 精确找到按钮。

02 · 逐步组合

状态由 JavaScript 保存和更新

核心互动
let days = 6;
button.addEventListener("click", () => {
  days = days + 1;
  dayText.textContent = `连续学习 ${days} 天`;
  button.textContent = "✓ 今天已打卡";
  button.classList.add("is-done");
});

变量 days 保存当前天数；点击时先加 1，再更新文字和按钮状态。这个小项目没有后端，所以刷新页面会恢复初始值——这是正常的，未来可以用 localStorage 或数据库保存。

03 · 项目检查

按层排查，不要混在一起

H
内容缺失：先查 HTML

C
样式不对：再查 CSS

选择器有没有选中？单位和分号是否完整？

J
点击无效：最后查 JavaScript

元素是否找到？事件名是否为 click？控制台有没有错误？
