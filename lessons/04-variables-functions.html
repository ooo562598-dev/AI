01 · 变量

给数据一个好找的名字

变量不是高深数学，它只是把一个值放好，再贴上名字。以后需要这个值时，直接用名字，不用重复写。

🏷️
像带标签的收纳盒

盒子里放 20，外面写 minutes。以后说 minutes，电脑就知道你在说那个 20。

app.jsx
const topic = "HTML";
let minutes = 20;
minutes = 25;
const

创建一个不打算重新装东西的盒子，例如学习主题。

let

创建一个之后可能更新的盒子，例如累计分钟。

=

这里不是“相等吗”，而是把右边的值放进左边的名字。

02 · 函数

把一组步骤装进“小机器”

函数可以接收原料，执行步骤，再给出结果。定义函数像制作机器，调用函数才是真的按下开关。

app.jsx
function makeMessage(topic, minutes) {
  return `${topic} 学习了 ${minutes} 分钟`;
}

const result = makeMessage("CSS", 30);
makeMessage

函数名，最好用动作开头，让人一眼知道它做什么。

(topic, minutes)

两个输入位置，也叫参数。

return

把加工后的结果送出函数。

makeMessage(...)

真正调用函数，并交给它两个具体值。

03 · 常见错误

名字和调用最容易出错

!
用了还没创建的变量

先写 const name = "小林"，后面才能使用 name。

!
定义了函数却没调用

只有 function greet(){...} 不会自动运行，还要写 greet()。

!
参数顺序弄反

函数期待 topic 在前、minutes 在后，调用时也要保持这个顺序。
