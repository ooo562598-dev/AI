01 · 标签

标签像成对的收纳盒

<p> 是开始标签，</p> 是结束标签，中间放段落文字。斜杠 / 表示“到这里结束”。

📦
盒子外面有名字

写着“书”的盒子里放书；写着 p 的标签里放段落。标签名帮助浏览器理解内容。

index.html
<article>
  <h1>今日计划</h1>
  <p>学习 20 分钟</p>
</article>
<article>

打开一个内容区域，里面可以继续放标题和段落。

<h1>

开始一个一级标题；后面的 </h1> 把它关上。

缩进

标题和段落向右缩进，表示它们住在 article 里面。

02 · 括号与引号

括号划范围，引号包文字

圆括号 ( ) 常放条件或传给函数的内容；花括号 { } 包住一组要执行的代码；引号告诉电脑“这里是普通文字”。

app.jsx
if (taskDone) {
  console.log("今天完成啦");
}
(taskDone)

圆括号中是要检查的条件。

{ ... }

花括号中是条件成立后执行的一组步骤。

"今天…"

引号包住需要原样显示的文字，引号本身不会显示。

03 · 常见错误

符号通常要成对

!
忘记结束标签

<p>文字 少了 </p>，后面的内容可能被一起装进段落。

!
混用不同引号

"你好' 一边双引号一边单引号，不是一对。

!
右括号缺席

编辑器常会高亮对应括号。点击左括号，看看它的搭档在哪里。
